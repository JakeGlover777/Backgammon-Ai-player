# 🎲 Backgammon AI Player

A Java-based Backgammon AI developed as part of my MSc Computer Science dissertation at Swansea University.

The project investigates how heuristic-based artificial intelligence can make effective decisions under uncertainty in a stochastic board game, where both dice rolls and opponent actions influence future game states.

## 🧠 About the Project

Backgammon presents an interesting AI problem because decisions must be made with incomplete knowledge of future dice rolls and opponent moves.

This project implements a playable Backgammon environment alongside a heuristic-based AI capable of evaluating board states and selecting moves based on strategically relevant features.

The project is being used to investigate the effectiveness of heuristic decision-making while considering both playing strength and computational cost.

## ✨ Features

- Complete Backgammon game logic
- Legal move generation and validation
- Dice-based stochastic gameplay
- Heuristic board-state evaluation
- Autonomous AI move selection
- Support for AI performance testing
- Java-based object-oriented architecture

## 🔬 AI Approach

The AI evaluates potential moves using a heuristic evaluation function designed to estimate the strength of resulting board states.

Board characteristics relevant to Backgammon strategy are used to compare available moves and select the most promising action.

The project is being extended to evaluate factors including:

- AI playing strength
- Computational cost
- Search depth
- Number of future branches explored
- Heuristic effectiveness
- Performance across large numbers of simulated games
